# Tooling & Productivity Guide

## Required Tooling
- Node.js 18+
- npm ou yarn
- TypeScript 5+

## Recommended Automation
- Pre-commit hooks com Husky
- Prettier para formatação
- ESLint para linting

## IDE / Editor Setup
- VSCode extensões: ESLint, Prettier, Tailwind CSS IntelliSense
- TypeScript strict mode

## Productivity Tips
- Use `npm run dev` para desenvolvimento
- Shadcn CLI para adicionar componentes UI
