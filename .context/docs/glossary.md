# Glossary & Domain Concepts

## Core Terms
- **Task**: Tarefa do sistema Kanban
- **Ticket**: Chamado/solicitação interna
- **Drive Item**: Arquivo ou pasta no sistema de arquivos
- **Chat Room**: Sala de chat (setor ou projeto)
- **Course**: Curso interno da plataforma

## Acronyms
- **RLS**: Row Level Security (Supabase)
- **SSR**: Server-Side Rendering

## Domain Rules
- Usuários pertencem a setores específicos
- Permissões baseadas em roles (Admin, Gerente, Colaborador)
